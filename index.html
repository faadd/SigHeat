Panduan opsi Termux + Python

Pasang aplikasi Termux dan Termux:API dari sumber yang sama. Beri izin sensor/lokasi sesuai kebutuhan. Ekstrak proyek ke HP, lalu buka folder proyek di Termux. 

pkg update
pkg install python termux-api
python -m pip install -r requirements.txt
cp .env.example .env
python termux_edge.py --check-sensors

Jalankan HP pertama dengan perintah berikut. Pada HP kedua, ganti hp-a menjadi hp-b. Ganti Project ID contoh agar sama dengan dashboard kelompok. 

python termux_edge.py hp-a --project sigheat_kelompok_07

Secara bawaan, edge menggunakan broker WSS publik yang tertera pada formulir Browser. Atur broker/kredensial melalui .env bila memakai akun kelompok. Tambahkan --share-location hanya jika ingin membagikan koordinat untuk peta.

Gunakan dua Browser atau dua Termux pada satu jaringan untuk perbandingan yang setara. Panduan lengkap tersedia dalam docs/ANDROID.md dan README.md di ZIP proyek.

Pengukuran membutuhkan HTTPS atau localhost. Buka alamat HTTPS aplikasi ini pada kedua HP.
